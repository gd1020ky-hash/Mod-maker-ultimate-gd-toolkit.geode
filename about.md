# Ultimate GD Toolkit

Phone-first Geometry Dash utility mod.

## Battle build goals

- Unified in-game SM menu instead of scattered Geode settings
- Native `.sm` route format
- Universal route representation
- Export pipeline for `.sm`, `.gdr`, `.gdr2`, `.echo` and future formats
- Pathfinder search/retry/verification architecture
- Existing toolkit controls preserved: macro mode, speed, music sync, frame counter,
  click sound, sound path, auto-decoration ID, AI model/API configuration

This ZIP is a source-development package. It is not a compiled `.geode`.
